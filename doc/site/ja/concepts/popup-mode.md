# アプリがウォレットを開く

`popup` は独立配置アプリの既定接続方向であり、名称は独立プロトコル頁の意味ではありません。

```ts
const keymaster = new KeymasterConnectClient({
  targetOrigin: keymasterDeploymentOrigin,
  mode: "popup"
});
const connected = await keymaster.login({ text: "ウォレットに接続", appIdentity });
```

既定で完全ウォレットホーム頁 `/` を通常ブラウザウィンドウまたはタブで開きます。専用プロトコル頁を開かず、ポップアップ寸法も設定しません。最終ウィンドウ形態はブラウザが決定します。初回呼出はユーザークリック由来とし、阻止を回避してください。

ウォレットは作成・取込・アンロックを先に完了してから ready を発行します。ready は転送可用のみ示します。ログインと逐次操作承認はいずれも完全ウォレットのアプリ接続センターと全体承認パネルで行います。既定 ready タイムアウトは二分であり、超過後は明示的に再接続してください。ウォレットを終了しません。

既定で各クライアントは自ウォレット文書を開き、他アプリウィンドウの再利用による opener 継承誤りを回避します。SDK は実際開いたウィンドウのみ識別し、ユーザーが手開きした任意ウォレットタブを探しません。開路は `popupPath` 設定（既定 `/`）に従い、`targetOrigin` 内でなければなりません。ウィンドウ名のアプリ跨ぎ共用はサポートしません。

`close()` はローカル待機任務を拒否し、元申請を努力取消しますが、`window.close()` を呼ばず、`connect.logout` を自動実行しません。錯誤・タイムアウト・Demo のアンマウント・切替先変更もウォレットを終了しません。現在の接続の取消は `logout()` を明示呼出ししてください。ウォレット終了はユーザーが決定します。

候補包の検証は公開 npm 発行と等価ではありません。対応版本の公開発行後にのみ精密依存を切替えてください。
