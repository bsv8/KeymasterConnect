# リリースノート

公開 npm 版は `0.1.8`、wire は v1 です。App Storage、接続復元、公開 `close()` API を削除しました。Identity、独立 cipher、outputs 支払、Channel と MSFile は維持します。

切断またはページ更新後、ウォレットを開くアプリは再ログインし、ウォレットから起動したアプリはウォレットから開き直します。SDK は認可の復元情報を保存せず、自動再接続や業務リクエストの再送を行いません。ページ離脱時は現在の binding に紐づくアンロード通知をベストエフォートで送信し、ウォレットが旧実行接続を終了できるようにしてから、応答を待たずにローカルの監視・タイマー・待機を整理します。長期的なアプリ操作許可はウォレットが別に管理します。署名済み・送信済みの処理はタブを閉じても取り消されません。
