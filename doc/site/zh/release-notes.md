# 发布说明

公共 npm 版本为 `0.5.0`，wire 保持 v1。本版新增 `msfile.streamseed.follow` 与 `msfile.streamseed.read`：按稳定请求编号跟随直播或回放轨道，读取已验证节点的类型、媒体块边界和字节范围，处理后端 `pending`、`available`、`end` 与 `stopped` 状态。节点序号使用十进制字符串，单次范围最多 256 KiB。

连接中断或页面刷新后，App 主动连接须重新登录；钱包启动的 App 须从钱包重新打开。SDK 不保存授权恢复记录、不自动重连、不重放旧业务请求。页面离开时客户端尽力发送带当前连接绑定的卸载通知，帮助钱包结束旧运行连接，再清理本地监听器、计时器和等待任务，不等待远端回复。长期应用操作许可由钱包独立保存，关闭页签不撤回已签名或广播的操作。
