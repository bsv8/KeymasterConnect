# 安全模型

- 来源：消息必须同时来自配置的精确 origin 和当前 Session Window。
- 钱包身份：网络和公钥共同确定身份；相同公钥的 main/test 记录隔离，不能靠缺省网络恢复。
- 定位与授权：公开公钥用于定位；执行仍核对当前身份、实际来源、确认与签名。旧运行句柄不会因同 Key 重导入而恢复。
- App 身份：Storage 和 MSFile 需要已验证的发行人签名；恢复时重新验证已有 proof，不能靠追加未签名参数升级身份。
- 用户确认：支付文案和授权策略由 Keymaster 控制，App 不能把支付伪装成普通操作。
- 私钥：SDK 只得到公开身份、签名、密文、消息和结果，永远得不到私钥或可复用共享密钥。

外部凭证由验证方按身份、签名、范围和自身有效期验证。本地重置或注销不修改已签发材料；也不恢复旧本地设置。
