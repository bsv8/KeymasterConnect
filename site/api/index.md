# @keymaster/connect v0.1.0

Official browser SDK for Keymaster Connect V1.

The package provides one type-safe client for direct popup integrations and
Keymaster-launched appView applications. Public request and result types are
re-exported from the same protocol contracts used by Keymaster itself.
